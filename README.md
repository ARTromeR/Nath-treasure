# Nath-treasure

Pixel art animado (tributo a la era The Black Parade) que se dibuja celda por celda,
escribe un mensaje y termina con una pregunta… con un botón "No" que no se deja pulsar.

- `index.html`: todo el sitio (HTML + CSS + JS, sin dependencias).
- `capturas/`: capturas en 375×812, 390×844, 768×1024 y 1440×900.

Basado en [DaniCodex/snoopy-pixel-art-con-mensaje](https://github.com/DaniCodex/snoopy-pixel-art-con-mensaje).
